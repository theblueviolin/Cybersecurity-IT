📖 About This Simulation

What is Log Analysis?

SOC analysts monitor authentication logs to detect security threats. Failed login attempts can indicate brute force attacks where attackers try multiple passwords. By analyzing patterns, analysts identify:

  • Brute Force Attacks: Multiple failed login attempts from same IP in short time
  • Distributed Attacks: Failed attempts from multiple IPs (indicates botnet)
  • Privilege Escalation: Unusual admin account activity
  • Time Anomalies: Logins outside business hours

Response Actions:

  • Block suspicious IP addresses (firewall/WAF)
  • Reset potentially compromised credentials
  • Enable multi-factor authentication
  • Investigate compromised accounts
  • Generate incident report for management
