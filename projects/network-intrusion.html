📖 Network Reconnaissance & IDS Concepts

What is Network Scanning?

Network scanning is the process of identifying active hosts and services on a network. Attackers use scanning to discover vulnerabilities. Defenders use similar tools (IDS/IPS systems) to monitor for suspicious scanning activity.

Common Ports & Services:

  • Port 22 (SSH): Secure Shell - Remote administration. Medium risk if exposed to internet.
  • Port 80 (HTTP): Hypertext Transfer Protocol - Unencrypted web traffic.
  • Port 443 (HTTPS): HTTPS - Encrypted web traffic. Lower risk.
  • Port 21 (FTP): File Transfer Protocol - Legacy, unencrypted. HIGH RISK.
  • Port 3306 (MySQL): Database service. Should NEVER be exposed to internet.
  • Port 445 (SMB): Windows file sharing. CRITICAL RISK - WannaCry, NotPetya exploited this.

Attacker Reconnaissance Workflow:

  1. Host Discovery: Ping sweep to find active IPs
  2. Port Scanning: Identify open ports
  3. Service Enumeration: Determine service versions
  4. Vulnerability Assessment: Check for known CVEs
  5. Exploitation: Attempt unauthorized access

How IDS/IPS Systems Work:

Intrusion Detection Systems (IDS) monitor network traffic for suspicious patterns. Intrusion Prevention Systems (IPS) actively block detected attacks. Both use:

  • Signature Detection: Match against known attack patterns
  • Anomaly Detection: Flag unusual network behavior
  • Port Scanning Detection: Alert when port scan activity detected
  • Service Version Fingerprinting: Identify vulnerable services
